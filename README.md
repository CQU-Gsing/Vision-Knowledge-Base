# Vision Knowledge Base（视觉知识库）

本知识库用于记录 GSing 视觉组的学习资料、开发过程和实践成果，涵盖计算机视觉、目标检测、数据集标注，以及机器人定位导航相关内容。

## 从这里开始

**视觉组入门推荐学习 Python**，便于开展图像处理、数据处理和模型调用。掌握一种编程语言即可，C 或 Python 都可以，不要求两种都学；已经会其中一种的同学，可以直接开始后续的视觉实践。

- [知识库说明](知识库说明.md)：知识库用途与参与成员。
- [前置](前置.md)：开始学习前的准备与常用资源。
- [大纲](大纲.md)：视觉识别、定位导航和通信方向的学习主题。

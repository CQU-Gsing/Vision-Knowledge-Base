##### 计算机是如何工作的？

我们可以把计算机想象成一个处理信息的机器，它有三个最基本的原则：

**输入、运算、输出：** 计算机硬件的基础就是执行这三种操作。你通过键盘、鼠标等设备给它输入信息，它进行运算，然后通过屏幕、打印机等设备把结果输出给你。无论多复杂的功能，比如玩游戏或处理文件，都只是这三种基本操作的组合而已 

**程序是指令和数据的集合：** 软件或程序其实就是一系列的指令和数据。指令告诉计算机要做什么（比如加法、减法），数据则是这些指令的操作对象 。当程序员写代码时，就是在排列这些指令和数据。

**计算机只懂数字：** 计算机的思维方式和我们人类不同，它不靠直觉，一切都是机械化地处理 。对计算机来说，所有信息，包括文字、图片、颜色等，最终都会被转换成数字来处理 。



##### 我们如何操作计算机工作？

我们计算机的组成核心就是CPU，它只会执行由二进制数字 0 和 1 组成的
机器语言 。CPU 的每一个指令、每一个操作都对应着一段特定的二进制代码 。例如，对 CPU 来说，`01010011` 这串二进制代码可能代表着执行加法运算，这种与生俱来、CPU 能直接理解的语言，也被称为`原生代码`。

直接用 0 和 1 编写程序对我们来说是极其困难且低效的 。为了方便人类编程，人们发明了更易于理解的编程语言

- 汇编语言： 这是比机器语言高一级的语言。汇编语言用一些类似英文单词的助记符来代表机器语言的指令 。例如`LD` 是 `Load`的缩写，`OUT` 是 `Output`的缩写 。当你用汇编语言写完程序后，需要一个汇编器把它翻译成机器语言，CPU才能执行 。

- 高级语言： 像 C 语言、Java、Python 等都属于高级语言。它们的设计更接近人类的思维，语法更简单，也更容易理解和使用 。高级语言编写的程序不能直接被CPU执行，而是需要一个叫做编译器的程序，把高级语言代码翻译成机器语言 。

当你用 C 语言编写代码时，其实是在用一种人类可以理解的方式，向计算机发出一系列指令和数据，这些指令和数据会经历几个步骤最终执行出来:

1. 编译： 你写的 C 语言代码首先会经过编译器处理，被翻译成计算机可以理解的机器语言 。

2. 执行： 编译好的机器语言程序会加载到内存中 ,CPU会逐条读取并执行这些指令，从而让计算机完成你预设的任务 。CPU内部有一个特殊的寄存器叫做`程序计数器`（PC），它存储着下一条要执行的指令的内存地址 。程序每执行完一条指令，PC 的值就会自动更新，指向下一条指令的地址,执行下一条指令。

##### 变量

要讲变量，要先了解一下内存空间，我们在上面提到过，控制计算机的工作就是对指令和数据的排列，数据被储存的地方就是内存空间，准确来说是我们可操作的内存空间，而其又被分为堆和栈，这两个概念我之后会讲。

那变量的作用就是让操作系统分配对应的内存空间，我们以变量 `int`为例，我们以一行代码

int A = 100;

为例，来看看发生了什么。

1. 编译器看到 `int`，就知道这个变量需要占用多大的内存空间, `int`占用 4 个字节

2. 接下来，操作系统会在内存的栈上分配出连续的 4 个字节空间给这个变量，假设分配到的起始地址是 `0x7ffee4b18abc`

3. 将数值 `100` 转换成二进制形式，然后存入从 `0x7ffee4b18abc` 开始的这 4 个字节的内存空间中

在其中，变量 A 就被映射到`0x7ffeeb18abc`这个内存地址，而数据类型`int`就规定了从`0x7ffeeb18abc`开始往后读 4 个字节，而这四个字节就是系统为这个变量划分的内存空间

这就是变量的基本概念，那么有哪些常用的变量类型呢？我列举几个，其他大家可以去查

**`int`**: 表示整数,有 4 个字节

**`short`**: 用于存储较小的整数，有 2 个字节

**`float`**: 用于储存单精度浮点数\(可以简单理解为小数\)，有 4 个字节

**`long`**: 在 32 位系统中和`int`一样是 4 个字节，64 位系统中则是8 个字节

**`long long`**: 用于存储非常大的整数，8个字节

**`char`**: 1 个字节

每种变量开辟的内存空间不同，而且解释机制也不同，如果写

int A ="我的天呐";

编译器就会报错，因为`int`的解释机制里不认识"我的天呐"，具体每种变量的用法，大家自己去查

但是这里要讲一下布尔类型，布尔类型`bool`,就是判断条件为真还是假的，bool 类型只有两种值，true 和false,当然也可以写成1 和 0，1 和true 是等价的，false 和 0 是等价的，我们在写程序的时候会有很多条件判断，bool 就是非常重要的标识符。

bool a = true;

bool b = 0;

然后说一下变量的关键字

1. `const`： 是"constant" \(常量\) 的缩写，它是一个类型限定符，用来告诉编译器这个变量不能被修改\.一旦一个 `const` 变量被初始化，任何试图修改它的行为都会导致编译错误

const int SECONDS\_PER\_MINUTE = 60;

SECONDS\_PER\_MINUTE = 61; // 编译错误

这是用来保护参数的，当你的函数需要接收一个指针，但你只是想读取它指向的数据，而不想（也不应该）修改它时，就应该使用 `const`

void print\_message\(const char\* message\) \{

printf\("%s\\n", message\);

message\[0\] = 'H'; // 编译错误，因为 message 是一个指向 const char 的指针

\}

2. `extern`: 是 "external" \(外部的\) 的缩写,它是一个存储类说明符，它的作用是告诉编译器,要声明一个变量或函数，但它的实体（定义）不在当前这个文件里，而在别的某个文件里,链接器将来会负责把它们找到并连接起来

3. 说一下声明和定义的区别

4. 定义,它会实际地分配内存空间，并（可选地）提供初始值,例如：`int global_counter = 0;`

声明,可以进行多次,它只是告诉编译器某个变量或函数的“签名”（类型和名字）但        不分配内存，例如：`extern int global_counter;`

> 适当讲深一点，满足好奇宝宝
> 
> C 语言的编译过程分为几个阶段，`extern` 的作用体现在编译和链接两个阶段的分工上
> 
> 1. 编译阶段：当编译器在一个文件（比如 `main.c`）中看到 `extern int global_counter;`，它不会报错说“找不到这个变量”，相反，它会在生成的 `main.o` 目标文件中记录下一个Unresolved Symbol，名字叫 `global_counter`
> 
> 2. 链接阶段：链接器的工作就是把所有的 `.o` 文件（比如 `main.o`, `helper.o`）和系统库组合成一个最终的可执行文件。当它看到 `main.o` 里有一个Unresolved Symbol `global_counter` 时，它就会去其他的 `.o` 文件里寻找这个符号的定义，当它在 `helper.o` 中找到了 `int global_counter = 0;` 这个定义（即内存分配的地方）后，它就会把 `main.o` 中所有引用 `global_counter` 的地方，都指向 `helper.o` 中为它分配的那个实际内存地址
> 
> 如果链接器在所有文件中都找不到这个定义，它就会报错：“`undefined reference to 'global_counter'`”
> 
> 

假设我们的项目由两个文件组成：`helper.c` 和 `main.c`

1. `helper.c`

\#include \<stdio\.h\>



int global\_error\_code = 0;



void report\_error\(const char\* message\) \{

printf\("ERROR: %s\\n", message\);

global\_error\_code = 1;

\}

2. `main.c`

\#include \<stdio\.h\>



extern int global\_error\_code; 



extern void report\_error\(const char\* message\);



int main\(\) \{

printf\("程序启动时，错误码是: %d\\n", global\_error\_code\);



report\_error\("网络连接失败"\);



printf\("发生错误后，错误码是: %d\\n", global\_error\_code\);



return 0;

\}

编译与运行

# 1\. 分别编译两个 \.c 文件，生成 \.o 目标文件

gcc \-c main\.c \-o main\.o

gcc \-c helper\.c \-o helper\.o



# 2\. 链接器将两个 \.o 文件链接成一个可执行文件

gcc main\.o helper\.o \-o my\_program



# 3\. 运行程序

\./my\_program

运行输出

程序启动时，错误码是: 0

ERROR: 网络连接失败

发生错误后，错误码是: 1

4. 赋值运算 

赋值是将一个值放入一个变量中，我们之前使用的符号是 `=`。但 C 语言还提供        了一套非常方便的复合赋值运算符，你或许没了解过的，它们是 `+=`, `-=`, `*=`,         `/=`, `%=` 等，代表先进行算术运算，再将结果存回左边的变量中。

##### 函数

和数学中的函数类似，编程中的函数接收一些输入，在函数内进行运算，再给一些输出，当然在我们实际的使用中函数的输出往往不是重点\(很多函数的类型都是void\)，我们会使用一些技巧让函数直接改变输入

来说说我们为什么用函数，其实我们用函数是为了简化我们的编码工作，函数大概有三个用,`模块化`,`代码重用`,`抽象`,模块化可以让我们专心于当前这个功能的实现而无需考虑对其他地方的影响，代码重用可以让我们少写很多代码，而且看的人也轻松很多，抽象可以让我们用一个函数的时候无需关心函数的具体实现，只需考虑输入和输出就行

现在来说说函数的构成，就像上面我们说的一样，函数就三部分，输入，运算，输出，一个函数大概长这样

int function\_name\(int x\)\{

balabala；

return alaala；

\}

我们来解析这个函数的组成，函数名`function_name`,和变量名一样用来标记这个函数，函数接收参数`int x`，这就是我们说的函数的输入，函数用这个输入进行运算,然后就是函数体,`{ balabala }`大括号里面的内容，就是函数的主体内容，函数类型`int`，这个类型决定了函数返回值的类型，如果是void 就是没有返回值,函数返回值`return alaala`这个 return 就是函数的返回命令，它决定了函数在这里结束并且返回`alaala`,这个返回值必须和函数类型相同\.

> 我们来讲一下函数是怎么工作的，当一个函数被调用时，系统会在栈空间为这个函数开辟出一整片内存空间，接下来，会将函数的输入参数复制一份到这个栈空间中
> 
> 注意是复制一份，就是直接在这个栈空间中创建一个传入参数的副本，所以函数中传入参数的改变并不会影响这个参数本身
> 
> 然后会将函数的返回地址也保存在栈中
> 
> 什么是返回地址呢？就是函数执行完后下一条指令的开始地址，函数需要知道这个地址才清楚函数执行完后该回到哪儿
> 
> 接下来会进行局部变量的分配，函数体中定义的那些变量，都会在这片栈空间进行分配
> 
> 等下简单介绍一下什么是堆什么是栈
> 
> 然后就是执行函数体中的指令了，执行完后就会返回返回值\(如果有\)，并销毁整个栈帧\(就是在栈中给这个函数开辟的内存空间\)
> 
> 

- 介绍一下栈和堆，栈和堆是两片不同的内存空间\(这样说其实不准确，它们在物理上同属一片内存空间，但是数据结构不同\)，栈的特点是后进先出，像一叠盘子，最后放上去的盘子总是最先被拿走，栈空间的内存是由编译器自动管理的，编译器自动开辟和销毁，同时栈空间的大小有限，且速度快，我们提到函数是在栈中的，同样，我们前面定义的变量也是在栈中的，栈空间在程序开始时自动被开辟，在整个程序结束时自动被销毁

- 堆呢，是一块更大的、更灵活的内存区域，用于动态内存分配。与栈不同，堆没有固定的分配顺序，你可以在程序运行时根据需要手动分配和释放内存。在 C 语言中，这通常通过 `malloc()`、`calloc()` 和 `realloc()` 等函数来完成，并使用 `free()` 函数手动释放，堆内存的生命周期由程序员控制。这意味着你需要自己决定何时分配内存以及何时释放它。如果忘记释放已分配的内存，就会造成内存泄漏，这会导致程序占用越来越多的内存，最终可能耗尽系统资源，堆的大小只受限于计算机的虚拟内存。你可以在运行时动态地创建任意大小的数据结构，但是堆的速度相对栈来说较慢

#### Part2 ：C 的梳理



还记得我们在最开始提到的**程序是指令和数据的集合**和**计算机只懂数字**吗，这在 C 中体现地淋漓尽致，C 语言的每一个语法特性，都完美地印证了这两点

当我们写下这样一行看似简单的代码时：

int a = 100;

我们实际上是在给编译器下达一个高级指令，编译器会将其翻译成一系列底层的、计算机能够理解的操作：

1. 数据：首先，`100` 这个我们人类认识的十进制数，会被转换成一个二进制数字 `01100100` ，因为这是计算机唯一能懂的形式

2. 指令：然后，`int a` 这部分告诉编译器，我们需要一块内存空间来存放一个整数。编译器知道 `int` 类型需要 4 个字节，于是它会向操作系统申请一块连续的、4 字节大小的内存

3. 集合：操作系统分配了这块内存，它会有一个独一无二的起始地址，比如 `0x7ffee4b18abc`。变量名 `a`，对我们程序员来说是这个变量的名字，但对计算机来说，它本质上只是一个方便我们记忆和使用的助记符，它真正关联的就是 `0x7ffee4b18abc` 这个内存地址

4. 赋值：最后的 `=` 运算符，则是一条指令，告诉 CPU 把数据 `01100100` 存放到从地址 `0x7ffee4b18abc` 开始的那 4 个字节的空间里

**所以，我们定义的所有变量，无论类型是什么，本质上都是在内存中的一块特定区域。我们通过变量名来间接地访问和操作这块内存**

再来看函数，当我们调用一个函数时，比如 `add(x, y)`，底层发生了什么？

我们在前面讲过，系统会在一个叫做“栈”的内存区域为这个函数开辟一个临时的“栈帧”。这个过程中最关键的两步是：

1. 传递数据：将参数 `x` 和 `y` 的值**复制**一份，存入到这个新的栈帧中。这意味着函数内部操作的是一个副本，而不是原始的 `x` 和 `y`。

2. 传递指令地址：将函数调用结束后的下一条指令的内存地址（返回地址）也存入栈帧。这样，当函数执行完毕后，CPU 才知道应该跳转回哪里继续执行。

无论是 `if-else` 的条件分支，还是 `for` 循环的重复执行，其底层实现都离不开“跳转”。CPU 内部的程序计数器（PC）本来是顺序地指向下一条指令的地址，而这些控制流语句会被编译器翻译成一系列的**条件跳转**或**无条件跳转**指令，直接修改 PC 寄存器的值，让它指向一个全新的内存地址，从而改变程序的执行流程。

梳理到这里，你应该发现了一个贯穿始终的核心概念——内存地址

- 数据存储在某个内存地址上。

- 变量名是某个内存地址的别名。

- 函数的调用与返回，依赖于对指令内存地址的保存和跳转。

- 程序的执行流程，就是 CPU 在不同内存地址之间跳转读取指令的过程。

我们之前的所有操作，都是通过变量名、函数名这些高级的、抽象的符号来进行的，编译器在背后为我们处理了所有与内存地址相关的复杂工作，而C 语言提供的让我们能够直接抓住内存地址的工具，就是指针

正如我们在 Part 1 中所定义的，指针就是一个用来储存内存地址的变量。理解了前面的一切，你就会明白指针并非一个多么神秘的概念，它只是将底层最本质的内存地址暴露给了我们。通过指针，我们将能够

1. 直接修改传入函数的数据，而不仅仅是操作一个副本

2. 在程序运行时，动态地向系统申请和释放任意大小的内存（堆内存）

3. 更高效地处理数组、字符串等连续的数据结构



#### Part3 : 指针\(进阶\)

现在我们回来讲指针，记得我们在Part1 说的吗？指针就是储存内存地址的变量，那它是储存哪里的内存地址呢？就是你赋值给指针的数据的首字节所在的内存地址，让我们看看指针变量如何声明

int \*p; 

这个`*`代表p是一个指针，它专门用来存放int类型变量的地址，同样的，你也可以写成这样

int\* p;

二者就用途来说没有任何区别，当然如果你考试的话可能会刁钻你找不同，但是那个很无聊，这里肯定也不说

你肯定好奇，指针不是存的内存地址吗？为什么有指针类型？不同指针类型有什么区别？

是的，指针存的是内存地址，但是指针本身就是一个变量啊，所以指针肯定有不同类型，那么不同类型指针存的东西相同吗？答案是，相同，例如

```c
int num = 16909060;

int *int_ptr = &num;

char *char_ptr = (char *)&num;
```

int\_ptr 和 char\_ptr 储存的地址都是0x16b466758，我们可以通过

```c
printf("int_ptr: %p\n", (void*)int_ptr);

printf("char_ptr: %p\n", (void*)char_ptr);
```

来求证。那现在肯定想问，那指针类型的不同有什么区别呢？答案是，指针类型的不同，决定了其对待内存的方式不同，我们知道，一个int 类型表示占用 4 个字节，而我们在讲变量那里讲到过，一个内存地址对应一个字节的内存空间，所以int 类型的指针在读取内存时，会连续读取四块内存，并把读取到的内存数据组合到一起，以整数的编码方式解码，而char 类型只会读取一块内存，并按照 ASCII 的编码方式解码,下面来求证

```c
#include <stdio.h>



int main() {

int num = 16909060;

int *int_ptr = &num;

char *char_ptr = (char *)&num;



printf("int_ptr reads: %d\n", *int_ptr);

printf("char_ptr reads: %d, %d, %d, %d\n",

*(char_ptr), *(char_ptr + 1), *(char_ptr + 2), *(char_ptr + 3));



printf("Address stored in int_ptr: %p\n", (void*)int_ptr);

printf("Address stored in char_ptr: %p\n", (void*)char_ptr);



return 0;

}
```

这段代码的输出结果为

int\_ptr reads: 16909060

char\_ptr reads: 4, 3, 2, 1

Address stored in int\_ptr: 0x16b466758

Address stored in char\_ptr: 0x16b466758

`int` 指针读取:`int` 指针 `int_ptr` 知道它指向一个 `int` 类型的数据,当我们对 `int_ptr` 进行解引用（`*int_ptr`）时，它会从地址 `0x1000` 开始，一口气读取 4 个字节，也就是 `0x04`、`0x03`、`0x02`、`0x01`,编译器将这 4 个字节重新组合成一个完整的 `int` 值 `0x01020304`，也就是十进制的 `16909060`因此，`int_ptr reads: 16909060`

`char` 指针读取:`char` 指针 `char_ptr` 知道它指向一个 `char` 类型的数据`char` 只占用 1 个字节,当我们对 `char_ptr` 进行解引用时，它只会读取当前地址的 1 个字节`*char_ptr`读取地址 `0x1000` 的内容，即 `0x04`,`*(char_ptr + 1)`指针向前移动 1 个字节（`char` 的大小），读取地址 `0x1001` 的内容，即 `0x03`,`*(char_ptr + 2)`：读取地址 `0x1002` 的内容，即 `0x02`,`*(char_ptr + 3)`：读取地址 `0x1003` 的内容，即 `0x01`,`char` 指针将一个 4 字节的 `int` 拆解成了 4 个独立的字节,因此，`char_ptr reads: 4, 3, 2, 1`



然后，两个基本概念

1. 取地址（`&`）

2. 作用:获取一个变量的内存地址

3. 规则：`&` 运算符是一个一元运算符，它作用于一个变量，返回该变量在内存中的起始地址,返回的地址类型是“指向该变量类型的指针”。例如，`int a = 10;`，`&a` 的类型就是 `int*`\.
示例：

```c
int num = 42;

int *p_num = &num;
```

在这个例子中，`&num` 的结果是 `num` 的地址，这个地址被赋值给了指针 `p_num`

2. 解引用（`*`）

3. 作用：通过一个指针访问它所指向的内存地址中的数据。

4. 规则：`*` 运算符也是一个一元运算符，但它作用于一个指针变量,它会访问指针所存储的地址，并根据指针的类型来确定要访问的内存大小,解引用操作可以出现在赋值语句的左边或右边，这意味着你可以通过指针来读取或修改它所指向的数据示例：

```c
int num = 42;

int *p_num = &num;



int value = *p_num; // 解引用，从 p_num 指向的地址读取数据,value 的值现在是 42



*p_num = 100; // 解引用，修改 p_num 指向的地址中的数据,num 的值现在变成了 100,
```

你不能解引用一个空指针（`NULL`），否则会导致程序崩溃



来个应用例子，让我们尝试写一个函数来交换两个变量的值，你会发现它无法工作

\#include \<stdio\.h\>



void swap\_fail\(int x, int y\) \{

printf\(" \-\> 进入 swap\_fail 函数: x = %d, y = %d\\n", x, y\);

int temp = x;

x = y;

y = temp;

printf\(" \-\> 离开 swap\_fail 函数: x = %d, y = %d\\n", x, y\);

\}



int main\(\) \{

int a = 10;

int b = 20;



printf\("调用前: a = %d, b = %d\\n", a, b\);

swap\_fail\(a, b\);

printf\("调用后: a = %d, b = %d\\n", a, b\);



return 0;

\}

输出结果

调用前: a = 10, b = 20

\-\> 进入 swap\_fail 函数: x = 10, y = 20

\-\> 离开 swap\_fail 函数: x = 20, y = 10

调用后: a = 10, b = 20

你会发现，`swap_fail` 函数内部确实成功交换了 `x` 和 `y` 的值，但 `main` 函数中的 `a` 和 `b` 却纹丝未动,这就是“按值传递”的体现：`swap_fail` 操作的只是 `a` 和 `b` 的副本 `x` 和 `y`，它们位于 `swap_fail` 函数自己的栈帧里，函数一返回，这些副本就被销毁了,如何解决？就是不传递值本身，而是传递存储着这些值的“内存地址”

现在，我们用指针来重写这个 `swap` 函数

\#include \<stdio\.h\>



// 一个使用指针来正确交换两个整数值的函数

// 参数是 "指向 int 类型的指针"

void swap\_correct\(int\* px, int\* py\) \{

printf\(" \-\> 进入 swap\_correct 函数\\n"\);

printf\(" \-\> 接收到的地址: px = %p, py = %p\\n", \(void\*\)px, \(void\*\)py\);



// \*px 代表“px 这个地址上的值”

int temp = \*px;

\*px = \*py;

\*py = temp;



printf\(" \-\> 离开 swap\_correct 函数\\n"\);

\}



int main\(\) \{

int a = 10;

int b = 20;



printf\("原始值: a = %d, b = %d\\n", a, b\);

printf\("a 的地址: %p, b 的地址: %p\\n\\n", \(void\*\)\&a, \(void\*\)\&b\);

// 调用函数时，传递 a 和 b 的内存地址

swap\_correct\(\&a, \&b\);



printf\("\\n调用后: a = %d, b = %d\\n", a, b\);



return 0;

\}

**运行输出：**

原始值: a = 10, b = 20

a 的地址: 0x7ffc\.\.\.a1b4, b 的地址: 0x7ffc\.\.\.a1b8



\-\> 进入 swap\_correct 函数

\-\> 接收到的地址: px = 0x7ffc\.\.\.a1b4, py = 0x7ffc\.\.\.a1b8

\-\> 离开 swap\_correct 函数



调用后: a = 20, b = 10

这次操作的就是数据本身而非其副本了

结构体就是把一堆变量打包在一起，因为 C 语言是面向过程的语言而不是面向对象的，我们常用结构体来模拟对象，总之，`struct` 是一种由程序员自定义的复合数据类型，来看下我们怎么定义

struct Student \{

int id;

float gpa;

char name\[50\];

\};

接下来我们看看如何来声明一个实例

struct Student student1; // 在栈上创建了一个 Student 实例

这里我们声明的结构体就是当变量类型来用的，`struct Student`

我们如何访问成员变量呢?使用 点运算符 `.` 来访问结构体实例的内部成员

student1\.id = 101;

student1\.gpa = 3\.8;

strcpy\(student1\.name, "Alice"\); // 对于字符串，需要使用 strcpy

我们如何初始化呢？

可以在定义变量时，使用 `{}` 按顺序为成员赋初值

struct Student student2 = \{ 102, 3\.5, "Bob" \};

为什么结构体放这里呢？因为可以用指针来做高效的操作

指向结构体的指针： `struct Student* p_student = &student1;`
通过指针访问成员： 我们不能写 `*p_student.id`，因为 `.` 的优先级高于 `*`。正确的写法是 `(*p_student).id`，但这非常繁琐。因此，C 语言提供了一个专门的箭头运算符 `->`作为语法糖, `p_student->id` 完全等价于 `(*p_student).id`
向函数传递结构体：按值传递 `void func(struct Student s)`会将整个结构体完整地复制一份传递给函数,如果结构体很大，这个复制操作的开销会非常大，效率低下,所以我们可以按指针传递 `void func(struct Student* ps)` 只复制一个指针给函数,函数通过这个指针直接访问原始的结构体,这是最高效、最常用、也是唯一能让函数修改外部结构体内容的方法

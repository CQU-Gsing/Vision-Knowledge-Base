# 卷积神经网络学习

卷积神经网络：可以拆分为卷积\+神经网络。

卷积神经网络（简称CNN），是机器学习的一种。通过CNN，能够让计算机进行图像的识别处理，可以进行人脸识别，图像处理等。

![image\.png](../media/02%20OpenCV%20与视觉基础/卷积神经网络学习/image%202.png)

比如，通过CNN模型训练，能够对公路上情况进行分析处理。

而卷积神经网络的操作，具体来说，可以分为以下几步：1\.卷积层 → 2\. 池化层 → 3\. 扁平化 → 4\. 全连接层 → 5\. 输出概率 → 6\. 计算损失 → 7\. 反向传播更新权重 → 重复训练。

# 什么是卷积神经网络？

我们知道，图像是由一个一个像素点构成，而最终的成像效果是由背后的像素的颜色数值所决定的。

![image\.png](../media/02%20OpenCV%20与视觉基础/卷积神经网络学习/image%204.png)

Eg\. 当我们把黑色设为0，白色设为1时，我们可以直观的看到显示的是数字7\.而经过CNN模型的训练后，计算机能够知道是7\.接下来，我会对识别的步骤进行一个简单的阐释：

1\.**提取图像的特征。**

我们会通过卷积核或特征过滤器，提取特征。这将在2个3\*3的卷积核中得到体现。

![image\.png](../media/02%20OpenCV%20与视觉基础/卷积神经网络学习/image%205.png)

计算完成后，我们会得到一个4\*4的特征图。我们可以根据特征图的像素值的大小，设定颜色的深浅。

![image\.png](../media/02%20OpenCV%20与视觉基础/卷积神经网络学习/image%207.png)

我们发现，再7的竖直部分，被很好的提取出来了，但是水平部分，却没有很好的提取出来。这是因为，原来的6\*6的特征图，被**降维成了**4\*4，**边缘的特征丢失了**。为了解决这个问题，我们引入了padding的扩充方法，先将原始的6\*6，扩充成8\*8,被扩充的部分设为0\.在特征提取计算后，转换后的特征图的像素同为6\*6\.

![image\.png](../media/02%20OpenCV%20与视觉基础/卷积神经网络学习/image%203.png)

垂直和水平特征全部提取。

## **2\.最大池化（max pooling）。**

将特征图进一步压缩，仅仅反应特征图中最突出的点。通过2\*2的矩形进行分割，得到了3\*3的矩形。每一个2\*2的矩形区域内，选取**最大的数值**作为3\*3的每一个分格。（比如在右下角的2\*2的方格中，最大的数值为3，所以在3\*3的右下角为3，以此类推）池化后的数据，保留了原始图片的**最精华的特征部分**。

![image\.png](../media/02%20OpenCV%20与视觉基础/卷积神经网络学习/image%206.png)

## **3\.扁平化处理。**

把处理后的两个3\*3的特征图叠加。做成一维的数据条。

通俗来讲，假设你之前用卷积层找出了图片的“边缘”“颜色”等线索（特征），扁平化后把这些线索排成**一列**。全连接层就像一群侦探，每个侦探负责分析这些线索的组合，最终投票决定图片是“猫”还是“狗”。

每个神经元（侦探）都和前一层的所有神经元（线索）连接。

这里会用到**权重和偏置**（类似侦探的经验值），通过计算得出分类结果。

![image\.png](../media/02%20OpenCV%20与视觉基础/卷积神经网络学习/image.png)

![image\.png](../media/02%20OpenCV%20与视觉基础/卷积神经网络学习/image%201.png)

## **4\.决策**

激活函数（如ReLU、Softmax）—— “决策规则”

ReLU（用在隐藏层）：

公式：`输出 = max(0, 输入)`

比喻：侦探只汇报“有用的线索”（正数保留，负数直接归零）。

优点：防止计算爆炸（梯度消失问题），速度快。

Softmax（用在输出层）：

比喻：把侦探的投票结果转换成概率。比如：

猫的概率：70%

狗的概率：30%

公式：对每个类别的得分做指数运算并归一化，输出总和为1的概率。

损失函数（Loss Function）—— “破案评分”

作用：计算模型的预测结果和真实答案的差距。

常用损失函数：

交叉熵损失（Cross\-Entropy）：用于分类问题（比如分猫狗）。

比喻：如果模型说“70%是猫”，但正确答案是“狗”，差距就很大，扣分严重。

均方误差（MSE）：用于回归问题（比如预测房价）。

## 5\.反向传播更新权重

作用：根据“破案评分”（损失值），**反向调整网络中的权重和偏置**（侦探的经验值）。

步骤：

从**输出层**开始，计算每个权重的“责任”（梯度）。

用链式法则把**误差一层层传回去**，更新权重。

比喻：侦探发现这次分类错了，回头检查是哪些线索（特征）没用好，下次更关注这些线索。



# 卷积神经网络的简单应用：

以下是一个基于python的卷积神经网络的对手写数字的识别的代码。

```Python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader
import matplotlib.pyplot as plt

# 1. 定义CNN模型
class SimpleCNN(nn.Module):
    def __init__(self):
        super(SimpleCNN, self).__init__()
        # 卷积层1：输入1通道（灰度图），输出16通道，3x3卷积核
        self.conv1 = nn.Conv2d(1, 16, kernel_size=3, stride=1, padding=1)
        # 池化层：2x2窗口，步长2
        self.pool = nn.MaxPool2d(kernel_size=2, stride=2)
        # 卷积层2：输入16通道，输出32通道，3x3卷积核
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, stride=1, padding=1)
        # 扁平化：将多维数据拉平
        self.flatten = nn.Flatten()
        # 全连接层：输入32*7*7（经过两次池化后图像尺寸为7x7），输出10类（数字0-9）
        self.fc = nn.Linear(32 * 7 * 7, 10)
        # 激活函数
        self.relu = nn.ReLU()

    def forward(self, x):
        # 卷积 → 激活 → 池化
        x = self.pool(self.relu(self.conv1(x)))
        x = self.pool(self.relu(self.conv2(x)))
        # 扁平化 → 全连接
        x = self.flatten(x)
        x = self.fc(x)
        return x

# 2. 加载数据（MNIST手写数字数据集）
transform = transforms.Compose([
    transforms.ToTensor(),  # 转为Tensor，并归一化到[0,1]
    transforms.Normalize((0.1307,), (0.3081,))  # 标准化
])

train_data = datasets.MNIST(
    root='./data', train=True, download=True, transform=transform)
test_data = datasets.MNIST(
    root='./data', train=False, download=True, transform=transform)

train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
test_loader = DataLoader(test_data, batch_size=64, shuffle=False)

# 3. 初始化模型、损失函数和优化器
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = SimpleCNN().to(device)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 4. 训练函数
def train(model, device, train_loader, optimizer, epoch):
    model.train()
    for batch_idx, (data, target) in enumerate(train_loader):
        data, target = data.to(device), target.to(device)
        optimizer.zero_grad()
        output = model(data)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()
        if batch_idx % 100 == 0:
            print(f'Train Epoch: {epoch} [{batch_idx * len(data)}/{len(train_loader.dataset)}] Loss: {loss.item():.4f}')

# 5. 测试函数
def test(model, device, test_loader):
    model.eval()
    test_loss = 0
    correct = 0
    with torch.no_grad():
        for data, target in test_loader:
            data, target = data.to(device), target.to(device)
            output = model(data)
            test_loss += criterion(output, target).item()
            pred = output.argmax(dim=1, keepdim=True)
            correct += pred.eq(target.view_as(pred)).sum().item()
    test_loss /= len(test_loader.dataset)
    print(f'\nTest set: Average loss: {test_loss:.4f}, Accuracy: {correct}/{len(test_loader.dataset)} ({100. * correct / len(test_loader.dataset):.2f}%)\n')

# 6. 训练并测试（共5轮）
for epoch in range(1, 6):
    train(model, device, train_loader, optimizer, epoch)
    test(model, device, test_loader)

# 7. 可视化一个测试样本
data, target = next(iter(test_loader))
with torch.no_grad():
    output = model(data[0:1].to(device))
    pred = output.argmax(dim=1).item()

plt.imshow(data[0].squeeze(), cmap='gray')
plt.title(f'Predicted: {pred}, True: {target[0]}')
plt.show()
```
